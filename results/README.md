# QCG Assignment 2: Quantum State Tomography

## Overview
This project implements a Transformer-based model to reconstruct theoretical quantum density matrices from Classical Shadow measurements (Pauli measurements).

## Structure
- `src/`: Source code.
- `outputs/`: Trained models.
- `docs/`: Detailed documentation.

## Quick Start
1. Install dependencies: `pip install -r requirements.txt`
2. Run training: `python -m src.train`
